### Skontrolované bez nálezu
- **Secrets**: žiadne kľúče, tokeny ani `.env` v repozitári ani v celej git histórii; frontend má len verejný publishable kľúč; service-role len v Edge Functions.
- **SQL injection**: frontend len cez supabase-js (parametrizované); SQL funkcie bez skladania dotazov z textu používateľa (dynamický SQL len s konštantami / `using`).
- **Autorizácia / IDOR**: RLS zapnuté na všetkých tabuľkách; všetkých 86 `SECURITY DEFINER` funkcií prejdených – kontrolujú člena, oprávnenie (`can()`), vlastníctvo alebo token (zdieľaná ponuka, verejný QR len pri zapnutom `public_scan`). Storage: všetky buckety súkromné, prístup podľa členstva vo firme z cesty súboru, limity veľkosti.
- **CSRF**: nepoužívajú sa cookies (token v hlavičke) – nie je relevantné.
- **SSRF / RCE**: server nerobí požiadavky na adresy od používateľa; Edge Functions volajú len pevné adresy.
- **Edge Functions**: `send-push` POST len so zdieľaným tajomstvom webhooku; `login` s vlastnou kontrolou; CORS `login` len pre povolené pôvody (`ALLOWED_ORIGINS`).
- **Heslá**: Supabase Auth – bcrypt; appka heslá nikde neukladá ani neloguje.
- **Chyby**: používateľ vidí všeobecné hlásenia; zachytené chyby len vývojár (RLS), automatické mazanie.
- **Debug**: žiadne debug endpointy; vývojové nástroje len pre `app_developers`.
